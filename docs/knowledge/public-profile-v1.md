# Ricky 公开职业资料

## 基础定位

Ricky（李富豪）是一名金融产品经理，拥有 7 年以上信贷行业经验，同时也是 AI 应用深度实践者、人工智能训练师（三级），关注企业知识库落地与个人生产力提升。

## 职业路线

- 点融网：从业务现场建立机构、资产与运营判断力。
- 还呗：从业务理解进一步进入交易结构与经济模型判断。
- 小象优品：扩展系统产品、平台标准化与跨部门落地经验。
- 海尔消费金融：在持牌机构完整约束下形成端到端金融产品落地能力。

## 核心能力

Ricky 的能力由六个相互递进的维度构成：

1. 机构与资产评估。
2. 交易结构设计与盈利模型测算。
3. 金融产品方案设计与跨部门目标协同。
4. 业务规则系统化与 PRD 落地。
5. 项目上线运营与数据经营分析。
6. 标准化沉淀与 AI 赋能。

## AI 与知识资产化实践

Ricky 正在把历史工作材料整理为证据、知识、方法论与能力单元，并通过权限管理、有限检索、RAG 和 Agent 机制构建可对话、可调用、可验证的数字分身。其目标不是简单汇总文件，而是把真实工作经验转化为能够迁移到新任务中的判断与执行能力。
